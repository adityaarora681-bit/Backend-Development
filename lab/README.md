# Experiment 07: ES6 and DOM Manipulation

## Theory
- **ES6 Features:** Covers block-scoped `let` and `const`, arrow functions, template literals, destructuring, spread/rest operators, default parameters, classes, modules, and promises/`async`/`await`[cite: 20, 21, 22, 23, 24, 25, 26, 27, 28].
- **DOM Manipulation:** Covers selecting elements (`getElementById`, `querySelector`, `querySelectorAll`), updating content (`textContent`, `innerHTML`, `innerText`), modifying attributes/styles (`classList`), and creating, appending, or removing nodes[cite: 30, 31, 32, 33, 34].

## Files
- `es6_features.js` — ES6 syntax, destructuring, spread/rest, and class inheritance examples[cite: 20, 22, 23, 24, 25].
- `index.html` & `dom_demo.js` — DOM selection, content updates, class toggling, and element creation[cite: 30, 31, 32, 33].
