# Experiment 05: JavaScript Arrays, Objects, and Functions

## Introduction
JavaScript is widely used in backend development[cite: 4]. Working with arrays, objects, and functions helps structure data and modularize application logic[cite: 3, 4].

## Key Concepts
- **Arrays:** Store multiple values in an ordered list and support operations like adding items (`push()`), reading by index, and updating elements[cite: 5, 8, 14].
- **Objects:** Store related data and behavior as key-value pairs, allowing properties to be added, read, and updated[cite: 5, 9, 14].
- **Functions:** Reusable blocks of code that group logic for specific tasks[cite: 5, 14].

## Experiment Overview
- **`script.js`:** Covers basic arrays, objects, and functions[cite: 7].
- **`script2.js`:** Demonstrates string methods (`toUpperCase()`, `toLowerCase()`, `split()`) plus array and object manipulation[cite: 8].
- **`index.html`:** Runs JavaScript in a web browser console[cite: 9].
- **`library.js`:** Implements an in-memory `library` array with `addBook(title, author)` and `findBook(title)` for the PBL task[cite: 11].
